## 1. 项目概述

### 1.1 项目背景

IDCU Agent 是一个基于微内核架构的实时代理程序，提供模块化、可扩展的服务平台。项目遵循 Vector_OS 跨平台架构设计，采用纯 C 语言开发，支持 Windows/Linux/macOS 多平台兼容。

### 1.2 核心特性

- **微内核架构**：轻量级内核，支持动态加载模块
- **模块化设计**：独立的功能库，按需使用
- **消息总线**：模块间高效通信
- **协程调度**：轻量级并发处理
- **跨平台支持**：Windows/Linux/macOS 兼容
- **丰富组件库**：20+ 个独立功能库
- **完整测试覆盖**：单元测试、集成测试、基准测试

### 1.3 项目目标

构建一个生产级的、高可用的、可扩展的实时代理平台，为上层应用提供完整的基础设施支持。
