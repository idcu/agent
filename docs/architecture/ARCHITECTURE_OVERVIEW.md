# 架构概览

本文档提供 IDCU Agent 的整体架构设计。

## 系统架构图

```
┌─────────────────────────────────────────────────────────────────┐
│                         应用层 (Applications                      │
├─────────────────────────────────────────────────────────────────┤
│  HTTP Server  │  监控模块  │  业务模块  │  管理接口  │
└────────────┴────────────┴────────────┴────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                      微内核层 (Microkernel)                   │
├─────────────────────────────────────────────────────────────────┤
│  模块管理器  │  消息总线  │  协程调度器  │  生命周期管理  │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                       核心库层 (Core Libraries)                   │
├─────────────────────────────────────────────────────────────────┤
│  Common  │  Log  │  Memory  │  Config  │  Network  │  ...   │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                       系统层 (System Layer)                        │
├─────────────────────────────────────────────────────────────────┤
│              操作系统 API / 硬件抽象层                        │
└─────────────────────────────────────────────────────────────────┘
```

## 数据流图

### 模块间消息传递流程

```
┌─────────────┐         ┌─────────────┐         ┌─────────────┐
│  模块 A   │         │  消息总线  │         │  模块 B   │
└─────┬─────┘         └─────┬─────┘         └─────┬─────┘
      │                      │                      │
      │   发布消息         │                      │
      │─────────────────────>                      │
      │                      │                      │
      │                      │   路由消息            │
      │                      │───────────────────────> │
      │                      │                      │
      │                      │   处理消息            │
      │                      │<───────────────────── │
      │                      │                      │
```

### 请求-响应模式

```
┌─────────────┐         ┌─────────────┐         ┌─────────────┐
│  发送者    │         │  消息总线  │         │  接收者    │
└─────┬─────┘         └─────┬─────┘         └─────┬─────┘
      │                      │                      │
      │ 发送请求(带ID)     │                      │
      │─────────────────────>                      │
      │                      │                      │
      │                      │  转发请求            │
      │                      │───────────────────────> │
      │                      │                      │
      │                      │  处理请求            │
      │                      │                      │
      │                      │  发送响应            │
      │                      │<───────────────────── │
      │                      │                      │
      │  接收响应            │                      │
      │<─────────────────────│                      │
      │                      │                      │
```
