# 3. 使用 C 语言开发

日期: 2026-04-12

## 状态

已接受

## 上下文

需要选择适合系统级开发的编程语言。

## 决策

使用标准 C 语言 (C11) 作为主要开发语言。

## 理由

- **性能**: C 语言提供接近硬件的性能
- **移植性**: 广泛支持各种平台和架构
- **控制力**: 精确的内存管理和资源控制
- **生态**: 丰富的系统级库和工具
- **简单**: 语言特性少，易于学习和维护

## 后果

- 需要手动管理内存
- 没有面向对象的原生支持（但可以模拟）
- 需要更多关注内存安全
- 可以与其他语言通过 FFI 集成
