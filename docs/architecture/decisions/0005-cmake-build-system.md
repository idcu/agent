# 5. 使用 CMake 作为构建系统

日期: 2026-04-12

## 状态

已接受

## 上下文

需要选择一个跨平台的构建系统。

## 决策

使用 CMake 作为主要构建系统。

## 理由

- **跨平台**: 支持 Windows, Linux, macOS 等
- **成熟**: 广泛使用，社区活跃
- **灵活**: 支持复杂的构建配置
- **集成**: 与各种 IDE 和工具链良好集成

## 后果

- 需要编写 CMakeLists.txt 文件
- 有一定的学习曲线
- 可以生成各种原生构建系统文件 (Makefile, Visual Studio 等)
